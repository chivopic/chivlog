今天的信息量很大，但真正值得留下来的其实没有那么多。

## Build

- 把 **chivlog** 从一个空仓库搭成了可用的个人博客：Astro + Markdown + plain CSS。
- 参考早期 Web 的极简风格，把页面控制在窄内容区、普通链接、衬线字体和大量留白，不再为了“像一个产品”而堆 UI。
- 完成了 GitHub `chivopic/chivlog` 与 Vercel 的 Git Integration。
- 实际提交了一次 commit 验证链路：`main` 更新后，Vercel 会自动构建并发布到 Production。
- 给博客加入了 Daily Review 模板，准备把它作为公开、长期可回看的成长记录。

## Learn

- 对 Transformer 的理解比之前更具体了一点：先抓住 token 之间如何通过 attention 建立关系，再逐层补全 Q / K / V、多头注意力和整体结构，比一上来背公式有效得多。
- 重新梳理了函数式编程和过程式编程，意识到“怎么组织状态与变化”比语法差异更重要。
- 对宏观里的利率、降息、CPI、非农和科技股之间的关系建立了一个基础框架。还远远谈不上会分析，但至少知道以后该看什么。
- 第一次更系统地练习游泳，也发现很多动作问题最终都可以拆成节奏、呼吸和姿势，而不是单纯“更用力”。

## Think

今天最喜欢的一个想法是：**内容本身就是 UI。**

一个个人网站不一定需要卡片、渐变、动画和复杂组件。对于博客来说，真正重要的可能只是：文字够清楚，链接够自然，结构够稳定，而且几年后仍然愿意继续写。

这也让我重新考虑个人项目的维护方式。很多东西不是缺功能，而是缺一个足够简单、可以持续使用的形态。
